## 1. 속도 변환 (차분)

### 배경

박막 두께 데이터는 물질이 지속적으로 쌓이는 구조이므로, 원시 그래프는 기본적으로 **우상향하는 누적 곡선** 형태입니다.  
이 형태에서는 미세한 정체나 순간적 흔들림이 쉽게 묻힙니다.

### 변환 방법

Y축을 현재 누적 두께 대신 **직전 시간 대비 두께 변화량**으로 바꿉니다.

$$\Delta \text{Thickness}_t = X_t - X_{t-1}$$

### 직관적 효과

| 변환 전 | 변환 후 |
|---|---|
| 지속적으로 우상향하는 곡선 | 평평한 직선 또는 일정한 펄스(Pulse) |
| 이상 구간이 전체 추세에 묻힘 | 이상 구간이 **스파이크(Spike)** 또는 **계단 단차**로 즉시 드러남 |

## 2. 상태 공간 변환 (State-Space Trajectory)

### 배경

두께 데이터를 시간축 대신 **동시에 수집된 타 센서 데이터를 X축**으로 사용해 2D 궤적을 그리는 기법입니다.

### 변환 방법

```
X축 = 챔버 내부 압력 (또는 가스 유량 등)
Y축 = 박막 두께
```

시간이 흐르면서 좌표가 이동하여 하나의 **궤적(Trajectory)** 을 형성합니다.

### 직관적 효과

- **정상 웨이퍼** → 일정한 타원 또는 루프(Loop) 형태의 대각선 궤적으로 집중
- **이상 웨이퍼** → 궤적이 이상한 방향으로 이탈하거나 **나비·매듭 패턴**으로 꼬임

## 3. 이동 표준편차 띠 (Rolling Std Band)

### 배경

그래프의 선 자체만 보는 것이 아니라, 데이터가 순간적으로 얼마나 요동치는지를 **시각적 폭(Width)** 으로 표현하는 방법입니다.

### 변환 방법

짧은 타임 윈도우(예: 5~10초)를 한 칸씩 밀면서 각 구간의 표준편차를 구한 뒤, 원래 두께 그래프 주변에 **음영 영역(Band)** 으로 덧입힙니다.

### 직관적 효과

- **정상 웨이퍼** → 음영 띠가 처음부터 끝까지 실처럼 가늘게 유지
- **이상 웨이퍼** → 특정 시점에 음영 띠가 **풍선처럼 갑자기 부풀어 오름**  
  → 해당 구간에서 고주파 노이즈(미세 진동 / 플라즈마 흔들림)가 급증했음을 즉시 포착

## 4. 재발 행렬 이미지 변환 (Recurrence Plot)

### 배경

시계열 데이터를 숫자의 나열이 아니라 **2D 명암 이미지(Pixel Grid)** 로 변환해 형태적 특징을 한눈에 비교하는 방식입니다.

### 변환 방법

시계열의 모든 시간대 쌍 $(t_i,\ t_j)$끼리 두께 차이를 전수 계산하여 $N \times N$ 격자 이미지를 생성합니다.

```
두 시점의 두께가 비슷할수록 → 밝은색
두 시점의 두께 차이가 클수록 → 어두운색
```

### 직관적 효과

- **정상 웨이퍼** → 규칙적인 사선 또는 체크무늬 형태의 대칭 이미지
- **이상 웨이퍼** → 이미지 중앙을 가로지르는 **거대한 십자형 흰 선**, 또는 특정 구역의 명암 블록이 통째로 일그러지는 현상

픽셀 패턴 매칭만으로 이상 웨이퍼를 즉각 분리할 수 있습니다.

## 5. 골든 프로파일과의 면적 누적 (Integral Area Delta)

### 배경

두 그래프가 엇비슷해서 겹쳐놓아도 식별이 어려울 때, 선 사이의 **미세한 틈새(면적)를 시간에 따라 증폭**시켜 단차를 키우는 기법입니다.

### 변환 방법

$t$ 시점까지의 누적 오차 면적을 새로운 시계열로 플롯합니다.

$$S_t = \sum_{i=1}^{t} \left| \text{Golden}_i - \text{Current}_i \right| \times \Delta t$$

### 직관적 효과

| 웨이퍼 상태 | 누적 면적 곡선 형태 |
|---|---|
| 정상 | 0 근처에서 잔잔하게 유지 |
| 이상 (미세 속도 차이) | 시간이 지날수록 **가파르게 우상향하는 직선** |

눈으로 구분되지 않던 얇은 격차가 거대한 단차 그래프로 **증폭·가시화**됩니다.

| 기법 | 핵심 변환 | 잡아내는 이상 유형 |
|---|---|---|
| 속도 변환 (차분) | 누적값 → 변화량 | 순간 정체, 계단 단차 |
| 상태 공간 변환 | 시간축 → 타 센서축 | 센서 상호작용 이상, 밸브 오작동 |
| 이동 표준편차 띠 | 원본 + 롤링 편차 음영 | 고주파 노이즈, 플라즈마 불안정 |
| 재발 행렬 (Recurrence Plot) | 시계열 → 픽셀 이미지 | 비연속·불균일 박막 형성 |
| 골든 프로파일 면적 누적 | 차이 면적 → 누적 시계열 | 미세한 증착 속도 차이 |

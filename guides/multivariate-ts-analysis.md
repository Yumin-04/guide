# 웨이퍼별 시계열 데이터 차이점 분석

> **목표**: Wafer 1, Wafer 2, … Wafer N의 시계열 데이터를 비교하여 각 웨이퍼 간 차이와 이상 패턴을 분석하는 대표적인 방법을 정리한다.

---

## 목차

- 문제 정의
- 방법론 개요
- 통계 기반 방법
- 시각화 기반 방법
- 거리·유사도 기반 방법
- 차원 축소 기반 방법
- 머신러닝·딥러닝 기반 방법

---

## 1. 문제 정의

반도체 공정에서 각 웨이퍼는 동일한 레시피로 처리되지만, 실제 센서 데이터(온도, 압력, 가스 유량 등)는 웨이퍼마다 미세한 차이를 보인다.

분석의 목적은 다음과 같다.

- 어떤 **시점(Time Point)** 에서 차이가 발생하는가?
- 어떤 **웨이퍼(Wafer)** 가 다른 웨이퍼와 다른 패턴을 보이는가?

---

---

## 3. 통계 기반 방법

### 기술 통계 비교

평균, 표준편차, 최대·최솟값, RMS 등의 통계량을 추출하여 웨이퍼 간 차이를 비교한다.

### 시점별 통계 비교

시점별 평균과 표준편차를 계산한 후, `|값 - 평균| > 3σ`를 벗어나는 구간을 이상으로 판단한다.

---

## 4. 시각화 기반 방법

- **오버레이 플롯** : 여러 웨이퍼의 시계열을 하나의 그래프에 겹쳐 이상 패턴을 확인
- **히트맵** : 웨이퍼와 시점을 색상으로 표현하여 특정 구간의 차이를 확인
- **컨트롤 차트(SPC)** : 평균 ±3σ 관리한계를 이용해 이상 시점 탐지

---

## 5. 거리·유사도 기반 방법

### Euclidean Distance

가장 기본적인 거리 계산 방법으로, 동일 길이의 시계열 비교에 적합하다.

### DTW (Dynamic Time Warping)

시간축이 늘어나거나 줄어든 시계열도 유사하게 정렬하여 비교할 수 있어 반도체 공정 데이터에서 많이 활용된다.

### Pearson Correlation

두 시계열의 패턴 유사도를 -1~1 범위의 상관계수로 계산한다.

---

## 6. 차원 축소 기반 방법

### PCA

시계열 데이터를 저차원으로 축소하여 웨이퍼 분포와 이상치를 시각적으로 확인한다.

### t-SNE / UMAP

비선형 차원 축소 기법으로 웨이퍼 간 군집 구조를 효과적으로 표현한다.

---

## 7. 머신러닝·딥러닝 기반 방법

### 클러스터링

K-Means, DBSCAN, K-Shape 등을 이용하여 유사한 웨이퍼를 자동으로 그룹화한다.

### 이상 탐지

Isolation Forest, One-Class SVM을 활용하여 정상 패턴에서 벗어난 웨이퍼를 탐지한다.

### Autoencoder

정상 웨이퍼를 학습한 뒤 복원 오차(Reconstruction Error)가 큰 웨이퍼를 이상으로 판정한다.

### Shapelet

시계열을 구분하는 핵심 패턴을 찾아 어떤 구간에서 차이가 발생하는지 해석할 수 있다.
